Produced by `scripts/30_report_figures.py`. Use these to check that the
refactored pipeline still reproduces the published results, and as the starting
point for any revision.

```bash
python scripts/30_report_figures.py                   # figures 5-8, 10, 11-14 (before)
python scripts/30_report_figures.py --with-training   # adds figure 9 (slow)
```

### Caveats on the four "reproducible" qualifications

**Figure 9 — "re-run only."** The published curves plot MSE against 100 epochs
with per-epoch evaluation, from a training run whose checkpoint was not kept.
`train_model` now records MSE alongside RMSE and `--with-training` re-runs both
models at `eval_every=1`, so the figure comes out in the published form — but it
is a fresh run, so the curves will not overlay the published ones exactly.

**Figures 10A / 10B — "approximately."** The layout, axes and panel order match.
The curves are drawn from the checkpoints in `models/`, which are not
bit-identical to the run behind the published figure, so individual points
differ slightly. The fit quality is the same.

**Figures 11–14 — "before only."** The "after" panels show speeds under the
proposed LQR tolling strategy. That scenario is generated by a separate
controller that is not part of this repository, and its output
(`modified_data_flow_included.csv` in the original working directory) is not
available here. If you have it, pass it through and the "after" panels are drawn
from the same code path:

```bash
python scripts/30_report_figures.py --scenario path/to/scenario_panel.csv
```

Note also that Figure 5 (left) and Figure 13 (before) are the same plot, as are
Figure 5 (right) and Figure 14 (before); both are emitted under both names so
each figure directory is self-contained.
